我們是您就醫旅程的第一站，也是最堅實的後盾

Department Overview & Core Values

奇美醫療財團法人佳里奇美醫院「醫療事務室」下設醫療服務組、住院服務組、申報業務組三大團隊。我們在醫院中扮演最前線且不可或缺的角色——從民眾踏入醫院掛號諮詢的第一刻，到治療結束辦理批價出院，我們都是與民眾接觸最密切的窗口；同時也是醫院與中央健康保險署對接、守護醫療財務穩健的重要核心。

面對不斷演進的醫療服務需求與健保政策，本室全體同仁秉持「品質、效率、同理心」的服務精神，持續優化智慧化櫃台與自助繳費流程，致力維護病人就醫權益並圓滿達成各項臨床行政支援任務，成為社區民眾信賴與院內同仁引以為榮的專業團隊。

💙 第一線溫暖服務

提供門診與急診掛號批價、雙向轉診協調及大廳服務台諮詢，用親切態度與高效率縮短您的等候時間。

🏥 一站式住出院支援

整合床位安排、病房帳務管理與各類診斷證明申辦，協助病人與家屬順利完成住院及出院手續。

📊 精準健保與財務管理

嚴謹把關門住院醫療費用申報、事前審查與健保規範遵循，確保醫療資源合理運用與醫院穩健營運。

醫療服務組｜工作職責介紹

涵蓋門急診掛號、門急診批價、大廳服務台及轉診服務四大業務

門急診掛批 / 轉診中心 / 服務台

一、門診、急診掛號服務

提供初診、複診病人掛號、取消服務。

二、批價服務

(一) 門診批價服務
  1. 門診批價收費及補卡、退費作業。
  2. 轉檢記帳作業。
  3. 補發副本收據及健保費用明細請領。
(二) 急診批價服務
  1. 急診批價收費及補卡、退費作業。
  2. 急診住院辦理。
  3. 協助辦理自動出院手續。
  4. 住院服務組非上班時段之住出院相關業務。
  5. 病房借用（歸還）被服押金。
  6. 補發副本收據及健保費用明細請領。
  7. 診斷書補發申請及用印。

三、服務台

  1. 服務台諮詢。
  2. 查詢醫師看診門診時間。
  3. 住院病人病房查詢。
  4. 協助預約掛號。
  5. 失物招領。

四、轉診服務

  1. 轉診轉入個案受理、回覆。
  2. 轉檢、轉代檢業務。
  3. 法院、勞保、保險文件查詢之案件受理。
  4. 病房轉診住院（轉院）協助預訂床業務。

住院服務組｜工作職責介紹

涵蓋住院服務櫃檯與住院批價（含開刀房批價）兩大作業區塊

住院批價 / 住出院櫃台 / 開刀房批價

住院服務櫃檯

共 10 項
  1. 辦理預約住院保留登記及訂床業務。
  2. 辦理住、出院手續及結帳。
  3. 住院病人床位及相關資料之查詢。
  4. 住院高貴藥材、衛材之批價及退藥。
  5. 各類證明書、收據之補發申請。
  6. 各項診斷書之加蓋影印。
  7. 應收帳款之資料整理及費用跟催。
  8. 承辦死亡證明書申請開立業務。
  9. 協辦病歷複製申請業務。
  10. 代辦業務：重大傷病身分申請、農（勞）保殘廢診斷書、身心障礙鑑定手冊、外籍看護工診斷書、勞工職業傷病住院申請書送件。

住院批價

共 10 項
  1. 辦理病人出入院、轉科及轉床手續。
  2. 核對住院病人帳目。
  3. 衛材計價管理。
  4. 協助護理站電話接聽及住院滿意度調查作業輸入。
  5. 其它科室檢查醫令接收錯退作業。
  6. 門診、急診、住院手術批價作業。
  7. 工作調配和指導新進書記線上作業。
  8. 配合申報組工作處理。
  9. 退藥流程作業。
  10. 其它臨時交辦業務。

負責門住診健保費用申報、抽審申覆爭議、事前審查與各項補助計畫申報作業

門診申報 / 住院申報 / 申覆爭議與事前審查

申報業務職責明細

Department Overview & Core Values

奇美醫療財團法人佳里奇美醫院「醫療事務室」下設醫療服務組、住院服務組、申報業務組三大團隊。我們在醫院中扮演最前線且不可或缺的角色——從民眾踏入醫院掛號諮詢的第一刻，到治療結束辦理批價出院，我們都是與民眾接觸最密切的窗口；同時也是醫院與中央健康保險署對接、守護醫療財務穩健的重要核心。

面對不斷演進的醫療服務需求與健保政策，本室全體同仁秉持「品質、效率、同理心」的服務精神，持續優化智慧化櫃台與自助繳費流程，致力維護病人就醫權益並圓滿達成各項臨床行政支援任務，成為社區民眾信賴與院內同仁引以為榮的專業團隊。

💙 第一線溫暖服務

提供門診與急診掛號批價、雙向轉診協調及大廳服務台諮詢，用親切態度與高效率縮短您的等候時間。

🏥 一站式住出院支援

整合床位安排、病房帳務管理與各類診斷證明申辦，協助病人與家屬順利完成住院及出院手續。

📊 精準健保與財務管理

嚴謹把關門住院醫療費用申報、事前審查與健保規範遵循，確保醫療資源合理運用與醫院穩健營運。

醫療服務組｜工作職責介紹

涵蓋門急診掛號批價、大廳服務台及轉診中心業務

門、急診掛批 / 轉診中心 / 服務台

一、門診、急診掛號服務

提供初診病人、複診病人掛號、取消服務（含醫師輪值掛號開檔維護）。

二、批價服務

(一) 門診批價服務
  1. 門診批價收費及補卡、退費作業。
  2. 轉檢記帳作業。
  3. 補發副本收據及健保費用明細請領。
(二) 急診批價服務
  1. 急診批價收費及補卡、退費作業。
  2. 急診住院辦理。
  3. 協助辦理自動出院手續。
  4. 住院服務組非上班時段之住出院相關業務。
  5. 病房借用（歸還）被服押金。
  6. 補發副本收據及健保費用明細請領。
  7. 診斷書補發申請及用印。

三、服務台

  1. 服務台諮詢。
  2. 查詢醫師看診門診時間。
  3. 住院病人病房查詢。
  4. 協助預約掛號。
  5. 失物招領。

四、轉診服務

  1. 轉診轉入個案受理、回覆。
  2. 轉檢、轉代檢業務。
  3. 法院、勞保、保險文件查詢之案件受理。
  4. 病房轉診住院（轉院）協助預訂床業務。

📌 本組兼辦專案與行政維護

  • 門急診颱災就醫服務及職傷電訪關懷。
  • 身心障礙鑑定作業與高風險病人召回就醫通知。
  • 醫師輪值掛號開檔維護。

住院服務組｜工作職責介紹

涵蓋住院服務櫃檯、住院批價及開刀房批價等全流程住院行政服務

住院批價 / 住出院櫃台 / 開刀房批價

一、住院服務櫃檯

共 10 項業務
  1. 辦理預約住院保留登記及訂床業務。
  2. 辦理住、出院手續及結帳。
  3. 住院病人床位及相關資料之查詢。
  4. 住院高貴藥材、衛材之批價及退藥。
  5. 各類證明書、收據之補發申請。
  6. 各項診斷書之加蓋影印。
  7. 應收帳款之資料整理及費用跟催。
  8. 承辦死亡證明書申請開立業務。
  9. 協辦病歷複製申請業務。
  10. 代辦業務：重大傷病身分申請、農（勞）保殘廢診斷書、身心障礙鑑定手冊、外籍看護工診斷書、勞工職業傷病住院申請書送件。

二、住院批價（含開刀房批價）

共 10 項業務
  1. 辦理病人出入院、轉科及轉床手續（含病床檔維護作業）。
  2. 核對住院病人帳目。
  3. 衛材計價管理。
  4. 協助護理站電話接聽及住院滿意度調查作業輸入。
  5. 其它科室檢查醫令接收錯退作業。
  6. 門診、急診、住院手術批價作業。
  7. 工作調配和指導新進書記線上作業。
  8. 配合申報組工作處理。
  9. 退藥流程作業。
  10. 其它臨時交辦業務。

申報業務組｜工作職責介紹

負責全院門住診健保費用申報、審查爭議處理及計價檔維護作業

門診申報 / 住院申報

一、醫療費用申報與專案作業

  1. 門住診醫療費用申報作業。
  2. 門住診抽審申報作業。
  3. 門住診申覆申報作業。
  4. 門住診爭議申報作業。
  5. 試辦計劃申報作業。

二、事前審查、補助計畫與計價維護

  1. 事前審查申報作業。
  2. 醫療院所戒菸服務補助計劃申報作業。
  3. 勞工保險預防職業病健康檢查申報作業。
  4. 相關健保業務查詢作業（含全院計價檔維護作業）。
